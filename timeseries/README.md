# Time series experiments

This directory contains the timeseries experiments: Neural CDE and Neural RDE classification on EigenWorms, PhysioNet 2019 Sepsis, and Speech Commands datasets.

# Installation

```bash
uv sync
```

# Experiments

```bash
# EigenWorms
uv run python experiments/eigenworms.py

# PhysioNet 2019 Sepsis
uv run python experiments/sepsis.py

# Speech Commands
uv run python experiments/speech_commands.py
```
